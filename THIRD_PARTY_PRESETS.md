# Third-party presets

Eighteen parametric files were copied from the public AutoEq results on GitHub. The repository license file is the MIT license, copyright 2018-2022 Jaakko Pasanen. Each card credits the measurement author named by AutoEq. This is a curated handful, not a clone of the AutoEq collection.

The in-app card loads AutoEq filters 1-5 and the 5-band preamp printed in that result's README. It is not the 10-filter correction. The original ParametricEQ text is kept so Import can review every filter.

No Kefine Loric parametric file was found in the AutoEq index. The Loric entries in the app are original starting voicings.

FiiO hand-picked presets are not in this list. The logged-out page at https://fiiocontrol.fiio.com/equalizer/hand-picked is an empty application shell, and the preset endpoints did not return public JSON.
